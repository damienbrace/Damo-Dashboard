## Visual Direction

Use a dark teal/cyan dashboard style.

Design rules:

- Dark navy/black background
- Cyan and teal accent colours
- Rounded cards
- Subtle gradients
- Soft borders
- Minimal glow effects
- Clean sidebar navigation
- Dashboard cards with clear spacing
- Calm, premium, modern look
- Avoid clutter
- Keep each page focused

The main mockup includes these page styles:

- Home dashboard
- Tasks
- Habits
- Finance
- Journal
- Life Admin

Use the mockup as inspiration, not a pixel-perfect copy.
