# LifeOS Docs

This folder contains the project planning documents for the LifeOS personal operating system app.

## Files

- `PROJECT_OVERVIEW.md` — high-level project summary
- `ROADMAP.md` — phased build plan
- `MODULES.md` — feature modules and purpose
- `DATABASE_OUTLINE.md` — suggested Supabase/Postgres table structure
- `AI_FEATURE_PLAN.md` — AI assistant behaviour and feature ideas

## Recommended First Build

Start with the MVP:

1. Authentication
2. App layout
3. Home dashboard
4. Tasks
5. Brain dump
6. Habits
7. Journal
8. Basic finance tracker
9. Life admin reminders

Do not start with bank integrations, grocery checkout, or complex AI automation.

Build the daily-use core first.
